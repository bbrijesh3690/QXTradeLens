# QXTradeLens Controller (unpacked extension)

This folder is the extension Chrome loads (`chrome://extensions` → **Load unpacked** → this folder).

- `content.js` is **generated**: edit `src/content.js` at the repo root and run `npm run build`.
- `popup.html`, `popup.js`, `service_worker.js`, `chart_reader.js` and `manifest.json` are edited here directly.

See the repository `README.md` for development, testing and the release workflow, and `CHANGELOG.md`
for version history.
